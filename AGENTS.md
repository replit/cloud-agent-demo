# Guidance for this preview demo

- **Scope:** Keep this a small, frontend-only educational landing page for Replit Cloud Agents. Do not add a backend, database, secrets, login, external services or analytics.
- **Private preview:** Keep the demo unpublished until explicit approval. Do not publish or distribute the unpublished source draft.
- **Independent practice:** Use your own independent repository created from an approved template or copy to practice changes. Do not push or open pull requests against the upstream demo repository.
- **Remote awareness:** Cloning alone does not remove the upstream remote. Inspect remotes before any Git operation. Do not perform external Git operations or create repositories without explicit authorization.
- **Pull request policy:** The upstream repository must have pull requests disabled for everyone, including maintainers. Configure and verify this through GitHub settings. These written instructions do not enforce permissions.
- **Separate work:** Do not touch `replit/replit-docs` or PR2307.
- **Honest UI:** Keep illustrations clearly labeled. Do not imply live customer data, actual test outcomes, working agents or product functionality. Use working local controls and anchor links, not fake forms.
- **Accurate copy:** Engineers review proposed changes and control what ships. Do not invent testimonials, metrics or availability. Omit unpublished rollout details, future integrations, webinar dates and internal performance figures.
- **Writing:** Use sentence case headings, positive informational copy, bold bullet labels with colons, and no em dashes.
- **Branding:** Use the included official Replit assets, a light theme and restrained orange accents. Never redraw the logo.
- **Portability:** Keep dependencies minimal and configuration self-contained. Preserve `npm install` and `npm run dev` with no required environment setup.
- **Verification:** Run `npm run typecheck` and `npm run build` after changes. Check responsive layout and keyboard access in the preview.
